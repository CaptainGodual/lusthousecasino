## Rebuilding

Tools/Release/Build-WindowsDemo.ps1 packages Windows Shipping. Tools/Release/Build-AndroidDemo.ps1 uses the private Windows-encrypted Android signing credential and Java 21 to produce ASTC Shipping with distribution signing. The Android helper restores Config/UserEngine.ini in finally and sanitizes generated signing text. Password-bearing local overrides are ignored by Git, and packaging removes signing password keys. Do not ship development helpers, Saved data, keystores, PDBs or AFS installer files.

Windows ZIP creation excludes private/developer artifacts; check Saved/ReleaseHardeningVerification/windows-package.json for the inventory result. Future builds must be checked again rather than reusing the present hashes.
