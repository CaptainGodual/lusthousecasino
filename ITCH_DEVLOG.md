# Sugar Lust Demo Build — Development Update

**Lust House is bringing Sugar Lust to Unreal Engine 5.8.** This demo is a first playable slice of the project: one candy-themed slot machine, wrapped in a neon casino lobby.

## What’s in this build

- A playable **Sugar Lust** slot with five reels, three visible rows, and 20 paylines.
- A candy-themed symbol set, including wilds and scatters.
- Animated reel spins, win highlights, and payline displays.
- A scatter-triggered candy jar bonus round.
- Bet controls, spin and auto-spin buttons, progressive jackpot meters, and win feedback.
- A custom lobby, slot cabinet artwork, music, and sound effects.

## What’s next

This is an early demo, and the project is still being tuned. More polish is planned for the slot presentation, bonus game, and player-facing features. The lobby shows several destinations that are not playable in this slice yet; **Sugar Lust is the playable game**.

## Build notes

- **Windows:** packaged Shipping build. Keep the complete Windows folder together when launching `SugarLustUE.exe`.
- **Android:** packaged for arm64 devices. This build includes a main APK plus a separate OBB data file, so installing only the APK may not be enough to launch the game. Android device installation is still being verified.

Thanks for checking out the demo and following development of Lust House!
